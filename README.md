# sinusoidal-noise-visualiser
Sinusoid Field — GPU-rendered, sinusoidal wave pattern generator for seamless looping desktop/OBS backgrounds. Runs entirely client-side in a single HTML file; exports looping WebM/GIF up to 4K.

Generate looping sinusoidal interference patterns for wallpapers and animated backgrounds. 

Inspired by a video on sinusoidal noise I built a little tool (with the help of Claude and lashings of Dr Pepper) that generates sinusoidal noise by dragging nodes across the image. There's a couple of effects like rippling and blurring to play with too. All colours are adjustable via the slider at the bottom.
